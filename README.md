# Auth Service (Сервис авторизации)

## 1. Назначение сервиса
**Auth Service** отвечает за аутентификацию и авторизацию пользователей. Он генерирует JWT-токены и проверяет их валидность при каждом запросе. Данный сервис является частью микросервисной архитектуры и взаимодействует с другими сервисами для предоставления доступа к защищенным ресурсам.

### Основные функции:
- Аутентификация пользователей.
- Генерация и валидация JWT-токенов.

---

## 2. Архитектура и зависимости

### **Технологии и фреймворки:**
- **ASP.NET Core** – основной фреймворк для разработки API.
- **Serilog** – для логирования.
- **Swagger** – для документирования API.
- **PostgreSQL** – база данных для хранения учетных данных пользователей.

### **Взаимодействие с другими микросервисами:**
- **DBProxy** – аутентификация запросов через JWT.

### **Используемые внешние сервисы:**
- PostgreSQL (база данных)

---

## 3. Способы запуска сервиса

### **Запуск с Docker**
```sh
docker-compose up --build
```

### **Запуск без Docker**
```sh
dotnet run
```

### **Переменные окружения (.env):**
```env
JWT_SECRET=your_secret_key
DB_CONNECTION_STRING=your_database_connection_string
```

---

## 4. API документация
Swagger UI доступен по адресу:
```
http://localhost:5000/swagger
```

### **Основные эндпоинты:**
| Метод | URL | Описание |
|--------|-------------------------|--------------------------------|
| POST | /api/auth/register | Регистрация нового пользователя |
| POST | /api/auth/login | Аутентификация и выдача JWT |
| GET | /api/auth/validate | Проверка валидности токена |
